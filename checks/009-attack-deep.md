## 方向加成判定（0x408db1，命中与伤害两侧都走）
开关 `[0x505f88]`==0 直接跳过。**全 EXE 扫描：该地址仅 0x408db9 一处 cmp 读取，无任何写入指令（A3/C6/88 形态全扫），.data2 初值 0 → 本 mod 方向加成恒关闭**（序章李明的"方向加成/地形利用"台词是引擎模板残留，mod 未启用）。
若开启则语义为（已破译备用）：按守方 dir(0下1左2上3右，见 0x449b27 switch) 与攻方相对坐标：
- 同轴面对攻方 → k=1（+5%）；同轴背对 → k=2（+10%）；异轴 → k=0；再同轴同侧(k=1) / 更近侧(k=2)
- bonus = hit×(k×5)/100，加到命中；伤害侧同函数
- 地形段：0x406710(cls<5=0, ≥2→1；[0x505f54]≠0 且 cls==3→2)；cls==5 且 [0x500e9a]==1 再 +5%

## 伪随机（0x437896 roll）
`[0x505fb4]` 同样全扫描无写入，.data2 初值 **2** → 恒走 0x47fb32 真随机（`rand31(seed*0x41c64e6d+0x3039)>>16 %100`，seed 初值 1 @0x48ecd4）。我们 `Math.random()*100 < hit` 与原版行为等价（伪随机 100 槽游标表 0x508f38+idx*100 预填、0x501bf6 游标数组是 mode≤1 死码，不移植）。

## 会心（0x405d0a 曲线 + 0x405d5b 入口）
- 输入 = **attr4（hit/运气）**双方对比（0x405d5f/0x405d77 push 4），非士气——与我们 `morale=bHit` 实现一致 ✓
- 曲线：a≥3d→100；2d≤a<3d→(a-2d)*80/d+20；d≤a<2d→(a-d)*18/d+2；a<d→1
- 琉璃七宝刀（0x40665c=attr3 且非 0x405dcf 格挡）→ 曲线 +100 = 必会心
- 会心伤害加成：dmg += dmg×(curve+100)/2/100（0x405ef0 段），黄金连环铠（key 0x41）格挡清 0
